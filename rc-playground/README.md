# Маленький заезд

3D-мини-игра в стиле «Город Свет» работает в двух вариантах: во дворе здания в конфигураторе вывесок и на отдельной странице. В обоих вариантах используется игрушечный пикап в стиле RAM TRX: широкие крылья, четырёхдверная кабина, открытый кузов, воздухозаборник, внедорожные колёса и логотип «Город Свет» на дверях, капоте и заднем борту. Модель и симуляция общие; геометрия площадки адаптируется к фасаду. Собственная HTML-точка входа входит в общую сборку Vite.

## Открыть

```sh
npm run dev -- --port 5174
```

При стандартном `VITE_BASE_PATH` откройте `http://localhost:5174/verkup/sign-configurator/`, выберите «Примерка · 3D», затем «Поиграть с машинкой». Площадка находится перед зданием с текущей вывеской. Заезд раскрывает существующее 3D-полотно на весь экран; «К вывеске» или Escape возвращает исходный ракурс и масштаб примерки. Выбранная вывеска, размещение и освещение сохраняются. В 2D игра недоступна.

Отдельная страница: `http://localhost:5174/verkup/rc-playground/`. При сборке с `VITE_BASE_PATH=/` адреса будут `/sign-configurator/` и `/rc-playground/`.

ЛКМ или касание: удерживайте и указывайте, куда ехать. Отпустите — машинка катится по инерции. ПКМ или пробел — тормоз. Shift с ЛКМ — задний ход. WASD и стрелки работают после фокусировки полигона: W/вверх — газ, S/вниз — назад, A/D — руль. Машинка плавно тормозит около курсора.

«Свободный заезд» позволяет исследовать полигон. «На время» запускает секундомер при первом нажатии газа: пройдите шесть ворот по порядку, активные ворота отмечены зелёным кругом. Лучшее время сохраняется на этом устройстве. «На старт» сбрасывает текущий заезд и возвращает все предметы на исходные места, сохраняя рекорд. Четыре камеры — «Полигон», «Следом», «Сзади» и «Детали» — работают также на паузе. «Сзади» даёт низкий ракурс за пикапом и смотрит вперёд по направлению движения.

В конфигураторе те же режимы называются «Свободно» и «На время»; доступны три камеры — «Площадка», «Машинка» и «Сзади». Кнопка паузы останавливает физику автомобиля, предметов и секундомер; сброс возвращает машинку на старт и восстанавливает предметы. Скрытая вкладка, невидимое полотно или потеря фокуса прерывают удерживаемое управление.

## Сцена конфигуратора

`SignScene3D.tsx` подключает `facadeGame.ts` к существующим сцене, ортографической камере, canvas и renderer. Вторая сцена, iframe и отдельный WebGL-контекст для заезда не создаются. На время игры обычное вращение примерки отключается, камера получает игровой ракурс; при выходе её состояние восстанавливается.

`world.ts` создаёт общую площадку, машинку и их визуальное состояние без камеры, renderer, обработчиков ввода или собственного цикла кадров. `game.ts` добавляет эти части для отдельной страницы и ES-модуля; `facadeGame.ts` использует уже работающий цикл конфигуратора. Пока заезд не запущен, площадка видна у здания, но её физика не выполняет шаги. Пауза также останавливает шаги симуляции.

`facadePlacement.ts` вычисляет положение по границам стены и тротуара в локальных координатах фасада, включая смещённые части углового здания. Масштаб — 200 мм на игровую единицу. Двор занимает полную ширину передней стены и соединяет существующий тротуар с площадкой глубиной 4400 мм перед ним. При смене варианта здания границы пересчитываются автоматически.

Три настоящие ступени входной лестницы и порог входят в общее поле высот: по ним можно заехать на верхнюю площадку. Дополнительный пол не закрывает лестницу. Клумбы и колонны козырька остаются неподвижными препятствиями для автомобиля и физических предметов. Игровые объекты не входят в геометрию вывески, её размеры и производственный экспорт.

## Встроить через iframe

Подставьте адрес опубликованной сборки. Никаких внешних скриптов или аккаунтов не требуется.

```html
<iframe
  src="/verkup/rc-playground/?embed=1"
  title="Мини-игра с радиоуправляемой машинкой"
  width="100%"
  height="560"
  loading="lazy"
  style="display:block;border:0;border-radius:16px"
></iframe>
```

Высота от 410 px. Встроенный режим убирает шапку страницы и нижние подсказки, сохраняя режимы, камеры, цвета и помощь. Если основная сборка размещена в корне, уберите `/verkup` из адреса. Для другого домена укажите полный URL игры.

## Отдельный виджет React

Для другого раздела сайта или отдельного виджета доступен React-компонент. Его CSS изолирован префиксом `rc-`. Импортировать игру лениво, когда пользователь её открывает:

```tsx
import { lazy, Suspense } from 'react';
const RcGame = lazy(() => import('../rc-game/RcGame').then(m => ({ default: m.RcGame })));

<div style={{ height: 560 }}>
  <Suspense fallback={<p>Загружаем машинку…</p>}>
    <RcGame embedded onLap={seconds => console.log('Круг:', seconds)} />
  </Suspense>
</div>
```

## ES-модуль для любого сайта

```sh
npm run build
npm run build:rc-embed
```

Второй шаг создаёт `dist/rc-embed/rc-game.js` с включёнными Three.js и Cannon ES. Выполняйте его после общей сборки, которая очищает `dist`. Он не зависит от React. Опубликуйте файл вместе с сайтом:

```html
<div id="rc-car" style="width:100%;height:520px"></div>
<script type="module">
  import { mountRcGame } from '/verkup/rc-embed/rc-game.js';
  const game = mountRcGame(document.querySelector('#rc-car'), {
    onTelemetry: state => { /* speed: км/ч; elapsed/best: секунды */ },
    onLap: seconds => console.log('Круг:', seconds),
    onError: message => console.error(message),
  });
  game.setMode('trial'); // 'free' или 'trial'
  game.setCamera('rear'); // 'overview', 'follow', 'rear' или 'detail'
  game.setColor('#3a8667');
  // game.setPaused(true); game.reset();
  // При удалении виджета обязательно: game.destroy();
</script>
```

`mountRcGame` создаёт сцену, камеру и renderer без интерфейса управления: его можно оформить самостоятельно. `onTelemetry` вызывается примерно десять раз в секунду. Контейнер можно изменять без повторного монтирования. Каждый экземпляр имеет собственные события и физику; `destroy()` освобождает геометрию, материалы, текстуры, WebGL-контекст, observers и кадры. При невидимом контейнере или скрытой вкладке игра останавливается. Клавиатура перехватывается только на сфокусированном полигоне.

## Физика и проверки

Автомобиль использует собственную игровую модель с фиксированным шагом 120 Гц: инерция, боковое сцепление, рулевая модель, тормоз и задний ход. Четыре независимых контакта с общим полем высот управляют пружинами и демпферами; корпус реагирует креном, тангажом и вертикальными колебаниями. Ограничители хода подвески поддерживают колёса над реальными ступенями и поднимают кузов при заезде на лестницу. Антенна — упругая цепь из десяти связанных сегментов с инерцией и ограничением длины.

`propsPhysics.ts` рассчитывает 25 независимых твёрдых тел в Cannon ES: четыре конуса, девять покрышек в трёх стопках и двенадцать столбиков ворот. У каждого тела своя масса, положение, вращение и инерция; действуют гравитация, трение, столкновения с землёй, машинкой и другими предметами. Покрышки могут отделяться от стопки, катиться и опрокидываться; конусы и столбики отлетают и падают после удара. Физические силуэты покрышек сохраняют отверстие. Кинематический коллайдер кузова передаёт движение автомобиля в Cannon, а рассчитанный встречный импульс возвращается в модель автомобиля как отдача. На паузе обе симуляции останавливаются; сброс восстанавливает позиции и ориентации предметов, обнуляя линейную и угловую скорость.

Автомобиль и предметы используют разные решатели: контактная подвеска автомобиля не является полной моделью твёрдого тела Cannon. Кузов автомобиля не переворачивается и не деформируется; предметы имеют полноценное вращение твёрдых тел. Обе симуляции используют согласованную поверхность и шаг 120 Гц.

```sh
npm run test:rc-game
npm run test:rc-props
npm run test:facade-rc
npm run build
npm run build:rc-embed
```

Тесты автомобиля проверяют торможение, инерцию, цель мыши, задний ход, зависимость от FPS, подвеску, антенну, стены и длительную устойчивость. Тесты предметов проверяют движение и вращение каждого типа после удара, отдачу автомобилю, гравитацию, распад стопки шин, контакт с полем высот, точный сброс и устойчивость при разных FPS. Проверки размещения используют настоящие модели фасадов и подтверждают ширину двора, соединение с тротуаром, высоты ступеней и порога, сохранение видимой лестницы и заезд автомобиля на верхнюю ступень.

Браузерные проверки используют Vite на 5174 и отдельный тестовый Chrome с `--remote-debugging-port=9334`. Например, в PowerShell на Windows запустите Chrome с профилем вне репозитория:

```powershell
$rcTestProfile = Join-Path $env:TEMP 'codex-rc-playground-profile'
$rcChromeArgs = @(
  '--headless=new', '--no-first-run', '--no-default-browser-check',
  '--remote-debugging-address=127.0.0.1', '--remote-debugging-port=9334',
  ('--user-data-dir="' + $rcTestProfile + '"'), 'about:blank'
)
Start-Process 'C:\Program Files\Google\Chrome\Application\chrome.exe' -ArgumentList $rcChromeArgs -WindowStyle Hidden
```

Проверка отдельной игры проходит круг реальными событиями мыши, проверяет касания, паузу, сброс, камеру деталей, встраивание и загрузку ресурсов. Проверка конфигуратора подтверждает один canvas/renderer, запуск на той же площадке, управление мышью и касаниями, паузу, сброс, переключение камер, восстановление ракурса по кнопке и Escape, сохранение ночного режима, мобильную компоновку и освобождение игры при переходе в 2D:

```sh
node scripts/test-rc-browser.mjs
node scripts/test-configurator-rc-browser.mjs
```

Можно задать `RC_GAME_URL` для отдельной игры, `RC_CONFIGURATOR_URL` для конфигуратора и `RC_CDP_URL` для Chrome. Профиль тестового Chrome не размещайте в репозитории: Vite не должен отслеживать его служебные файлы. Скриншоты сохраняются в `.impeccable/review/rc-game-*.png` и `facade-rc-*.png`. После проверки закройте отдельный тестовый Chrome.
