# Студия вывесок Веркуп

Самостоятельная страница конструктора: `/verkup/sign-configurator/`.

## Что изменилось

До переработки параметры были собраны в длинной панели, а надпись, материалы, свечение и монтаж конкурировали за внимание. Проект существовал только в текущем состоянии страницы.

После переработки настройки разделены на «Надпись», «Цвета», «Свет», «Монтаж» и «Логотип». У панели-кронштейна доступны «Форма», «Цвета» и «Логотип». Предпросмотр, день/ночь, масштаб и сводка конструкции собраны в рабочую область. Добавлены сохранение проекта JSON, открытие JSON, локальное автосохранение, удаление загруженного изображения и сообщения об ошибках.

Страница использует самостоятельные стили `sign-studio-base.css` и `sign-studio.css`; общий CSS CRM объемом около 349 КБ больше не загружается конструктором.

Сохранены все 34 параметра исходного конструктора. Выбор материала остается по каталожным палитрам Oracal 8500, Oracal 641 и АКП.

## Локальный запуск

В каталоге репозитория:

```powershell
npm install
npm run dev
```

Открыть [локальный конструктор](http://localhost:5173/verkup/sign-configurator/). Если порт 5173 занят, использовать адрес, который напечатает Vite.

Проверка сборки:

```powershell
npm run build
```

Команда выполняет TypeScript-проверку и собирает обе точки входа Vite. Базовый путь по умолчанию — `/verkup/`; его можно изменить переменной `VITE_BASE_PATH`.

## Доступные параметры

| Конструкция | Параметры |
| --- | --- |
| Общие | Тип изделия, дневной/ночной режим |
| Панель-кронштейн | Круг, квадрат или скругленный квадрат; размер 400–700 мм с шагом 50 мм; изображение; масштаб 45–130%; сдвиги X/Y −40…40%; цвета лица и борта |
| Объемные буквы | Текст до 60 символов; шрифт; высота 120–1200 мм; глубина борта 30–160 мм; цвета лица и борта |
| Свечение | Лицевое, лицевое/торцевое, лицевое/контражурное и контражурное; включение и цвет контражурной подложки |
| Кантик | Отдельные переключатели для букв и логотипа; общий цвет кантика |
| Логотип букв | Круг, квадрат или скругление; загруженное изображение; масштаб 45–130% |
| Монтаж | Стена, рама или подложка АКП |
| Рама | Профиль 15 × 15 или 20 × 20 мм; отступ от края 0–120 мм; верхняя труба 25–60% высоты; нижняя труба 12–45% от низа |
| Подложка АКП | Ширина 400–20 000 мм, высота 250–10 000 мм, глубина 30–100 мм и цвет; схема развертки с вторым подворотом 25 мм и листами 1500 × 4000 мм |

Параметры рамы и АКП появляются при соответствующем способе монтажа. Контражурная подложка доступна для режимов с ореолом, кроме монтажа на раме. Переключение изделия сохраняет настройки обоих типов.

## Проект и экспорт

- Автосохранение происходит через 450 мс после изменения в `localStorage` браузера под ключом `verkup-sign-studio-v1`. Оно зависит от устройства, браузера и адреса страницы; переноса между устройствами нет. Если запись недоступна, интерфейс предлагает скачать проект.
- «Сохранить проект» скачивает JSON с оболочкой `{ "version": 1, "project": { ... } }`. В файл входят параметры обоих изделий и изображения; вкладка настроек и масштаб предпросмотра не входят. «Открыть» восстанавливает настройки и возвращает масштаб к 100%.
- Импорт проверяет версию, значения перечислений, числа, булевы параметры, текст и коды палитр. Числа приводятся к разрешенным диапазонам, отсутствующие параметры заполняются значениями по умолчанию. Цвета восстанавливаются из каталога по коду.
- Загрузка изображений поддерживает PNG, JPG и WebP до 2 МБ с проверкой декодирования в браузере. JSON ограничен 6,5 МБ, встроенное изображение — 3 млн символов data URL.
- SVG сохраняет макет, цвета, изображение и конструктивные элементы. Текст букв остается SVG-текстом, а не кривыми: результат зависит от доступности выбранного шрифта у получателя. Для изготовления потребуется отдельная подготовка в векторном редакторе.

Цена автоматически не рассчитывается. Сводка показывает геометрию, материалы, свечение, монтаж и габаритную площадь. Площадь букв — оценка по габариту надписи, а схема листов АКП — прямоугольная раскладка без оптимизации раскроя. Экранные цвета служат для предпросмотра; физический цвет выбирают по образцу материала.

- Финальный снимок [desktop.jpg](artifacts/sign-studio/desktop.jpg) проверен при 1440 × 1000: макет виден целиком, настройки и основные действия читаются, критических обрезаний нет.
